# 内部32位位运算向量辅助

用于独立消息SM3的SIMD原语，不依赖算法族。尚未提出稳定公共数学API。

存储和逻辑值为uint32，Add/Sub调用int32位视图的向量指令以得到模2^32位模式，未使用有符号C++溢出表达式。And/Or/Not以相同字节的两半uint16视图执行；Xor用 `(a|b)-(a&b)`，逐位无借位，等于异或。逻辑旋转与字节序变换使用无符号移位及按位组合。

调用者提供6×n个uint32的scratch，不能与参数向量重叠；参数向量起点对齐32字节，n使用32/64/128候选。Rotl的r前提为0–31；Permute的两个旋转都在此范围。允许本实现已验证的d=a/d=b别名，不能任意重叠不同向量区间。同步由辅助函数和调用方的跨流水事件共同保证。

真实设备测试 `sm3_u32_probe` 检查65536组输入：256组边界位模式全组合，其余固定种子随机。对照主机定义明确的uint32计算，检查模加、模减、异或、与、或、非、旋转、P0及字节序，包含原地操作。整体SM3另与独立纯C及OpenSSL差分。该数学验证不等于一般私钥算法的常时证明。
