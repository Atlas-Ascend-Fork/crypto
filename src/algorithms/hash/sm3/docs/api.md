# SM3 设备接口

公共头文件为 `cann_crypto/sm3.h`，CMake 安装目标为 `CannCrypto::sm3`。

- `input` 是设备输入地址，消息按条连续存放。每条消息的长度由 `inputLength` 指定，单位为字节。库负责标准 SM3 填充。
- `output` 是设备输出地址，起址须 32 字节对齐。第 i 条摘要从 `output + 32*i` 开始。输入与输出有效区间不得重叠。
- `batch` 是消息条数。输入、输出总字节数以及单条长度均须在 UINT32_MAX 内。长度为零时允许空输入地址。通过尺寸校验的空批次直接返回成功。
- `stream` 由调用者在当前 ACL context 中创建。库依序提交计算并同步该流。调用者负责设备内存、context 和 stream 的生命周期。
- 返回零表示成功。参数错误发生于启动之前。运行时失败后设备输出内容未定义。

[纯 C 调用示例](../../../../../examples/sm3/hash.c)演示调用者如何分配设备缓冲区和搬运数据。
