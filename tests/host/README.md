# host —— 无需昇腾设备的测试

在没有 NPU、没有昇腾工具链的机器上即可编译运行，因此放在 PR 门禁里。

内容：

- **KAT**：NIST ACVP、Wycheproof 与 GM/T 标准向量，向量由 `../../scripts/` 下的脚本获取并校验哈希
- **差分测试**：以 `../../reference/` 的纯 C 参考实现为基准
- **ABI 兼容**：公共头文件的结构体大小、字段偏移与导出符号
- **负面用例**：错误 tag、非法长度、count 为 0、offsets 非单调、输入输出缓冲区重叠
- **fuzz**：Host 侧参数解析

约束：不得依赖任何 CANN 运行时接口，否则会失去「无设备可跑」这一前提。
