# 参考实现

各算法的纯 C 参考实现，是差分测试的正确性基准（oracle）。

## 约束

- **只求显然正确，不做任何优化。** 可读性优先于性能。
- **零 CANN 依赖。** 必须能在没有昇腾设备、没有昇腾工具链的机器上单独编译成 `libcann_crypto_ref.a`，否则 KAT 与差分测试进不了 PR 门禁，只能退到每日构建。
- **不得 include `src/` 下的任何文件。** 一旦与被测实现共享代码，它就不再是独立的 oracle。允许依赖的只有 `include/cann_crypto/` 与 libc。

## 用途

- `tests/host/` 中的差分测试以本目录为基准
